**riftFG** is a configurable guild plugin for **Paper 26.3+ servers running Java 25**,
developed as a fork of [FunnyGuilds 5.x](https://github.com/FunnyGuilds/FunnyGuilds/tree/5.x).
Players create guilds, claim territory, form alliances and
compete in rankings; admins configure each of those areas separately.

## Server compatibility

:::note[Minimum requirements]
riftFG requires **Paper 26.3+ and Java 25**. All adapters for older servers have been removed. Building and testing require only **JDK 25**; select it as the Gradle JVM in your IDE as well.
:::

The only NMS adapter, `v26_3`, is compiled against Paper `26.3.build.249-stable`. It does not inherit from older adapters. The entire plugin and all NMS modules produce Java 25 bytecode. Older servers reject `api-version: '26.3'`, and the internal data-version check additionally requires at least `5023`.

A newer server data version tries the 26.3 adapter and displays an unverified-compatibility warning; a Minecraft update may require a new adapter. Archived FunnyGuilds releases have separate requirements and do not describe current riftFG compatibility.
