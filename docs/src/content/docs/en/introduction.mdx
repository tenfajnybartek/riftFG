**FunnyGuilds** is a configurable guild plugin for Paper- and Spigot-based
Minecraft servers. Players create guilds, claim territory, form alliances and
compete in rankings; admins configure each of those areas separately.

## Server compatibility

:::note[riftFG support roadmap]
The current riftFG release is the last to support Minecraft **1.21.x**. Future releases will require **Minecraft 26.3+ and Java 25**; support for every older version, including earlier 26.x releases, will be removed.
:::

The 5.x source tree contains NMS adapters for Paper 1.21, 1.21.2/1.21.3, 1.21.4, 1.21.9, 26.1.1 and 26.3. Earlier adapters are reused between these baselines. Plugin bytecode targets Java 21; the 26.x adapters target Java 25. A newer server data version produces an unverified-compatibility warning. Archived 4.x releases on the download page have separate requirements and do not describe 5.x compatibility.
